Amor Animal
Sobre o projeto

O Amor Animal é um site desenvolvido como projeto de estudo, com a ideia de apresentar o trabalho de uma ONG de proteção animal. O objetivo é divulgar a causa, mostrar os animais e incentivar a adoção responsável.

Funcionalidades
Apresentação dos animais disponíveis para adoção.
Formulário demonstrativo de cadastro.
Página com informações sobre o projeto.
Opção de alternar entre tema claro e escuro.
Layout adaptado para computadores e celulares.
Navegação pelo teclado.
Tecnologias utilizadas
HTML5
CSS3
JavaScript
Vite
Git e GitHub
Netlify
Como executar o projeto

Clone o repositório:

git clone https://github.com/Socrates-aluno/amor-animal.git

Acesse a pasta do projeto:

cd amor-animal

Instale as dependências:

npm install

Inicie o projeto:

npm run dev

Testes realizados
Teste de funcionamento em computadores e celulares.
Teste básico de navegação pelo teclado usando a tecla Tab.
Verificação do processo de build.
Observação

Este projeto é apenas demonstrativo. O formulário de cadastro não envia informações para um servidor.
